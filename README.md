# Goral Bhatt — Healthcare Market Intelligence Portfolio

A recruiter-facing portfolio for Goral Bhatt, a healthcare market intelligence analyst. The site presents experience in medical-device research, competitive intelligence, tracker design, biosimilar research, and regulated documentation.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
```

## Project structure

- `app/page.tsx` — portfolio content and page structure
- `app/globals.css` — visual system and responsive layout
- `components/SiteHeader.tsx` — responsive navigation
- `public/` — résumé, hero image, and social-sharing image

The source is configured for OpenAI Sites through `.openai/hosting.json`.
